# Academy Observatory — Concept v1

**Uso:** dirección de arte para blockout Blender; no es arte final ni textura.

## Invariantes de modelado

- Edificio de aprendizaje escalonado, con aulas/estudios acústicos como módulos
  arquitectónicos y no como instrumentos decorativos.
- Terraza-observatorio y faro de señal central identificable a miniatura.
- Pasarelas técnicas, vidrio ahumado vertical y base pesada.
- Grafito/acero/vidrio ahumado; únicamente emisión esmeralda controlada.
- Planta hexagonal, 30°/60°/90° y biseles visibles.

## Prompt de exploración

```text
4U Studio Academy Observatory, Engineering Megacity v1: a grounded 38m terraced
hexagonal learning observatory with classroom and acoustic studio modules,
roof observation deck, narrow central emerald signal beacon, smoke glass and
technical walkways. Use graphite/dark steel/black titanium with #00D26A/
#5CFF9D as the only emissive colors. Avoid music icons, instruments, text,
logos, warm or blue emission, white concrete and 45-degree forms.
```

## Generación

Generada el 2026-07-30 con la herramienta de imagen integrada, solo para
