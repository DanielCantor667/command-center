# Intranet ESS Campus — Concept v1

**Uso:** dirección de arte para el blockout de Blender; no es una textura ni
arte final para web.

## Invariantes de modelado

- Campus administrativo ERP apilado alrededor de un patio interior visible.
- Puentes técnicos y bandas regulares de ventanas verticales para comunicar
  sistema, no una torre genérica.
- Base pesada, módulos repetibles y núcleo de datos legible.
- Grafito, acero oscuro, vidrio ahumado; solo emisión esmeralda discreta.
- Geometría hexagonal/30°/60° y bordes biselados.

## Prompt de exploración

```text
Intranet ESS Campus, Engineering Megacity v1: 42m stacked hexagonal corporate
ERP campus with open interior courtyard, two technical bridges, vertical
smoked-glass window bands, compact data spine and heavy grounded base. Use
graphite/dark steel/smoke glass with restrained #00D26A/#5CFF9D signals,
humid night and cold non-emissive rim. Avoid text, logos, blue emission,
white concrete, rainbow neon and 45-degree geometry.
```
