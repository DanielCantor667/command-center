# v0.3.0-alpha

Fecha: 2026-07-01 (Foundation) → 2026-07-02 (Design System Core)

## Resumen

Primera versión alpha de Command Center. Cubre el bootstrap del monorepo, el Foundation Engine
(tokens + theming) y el Design System Core (`packages/ui`). Sin producto ni pantallas de
aplicación todavía — es la base técnica sobre la que se construye todo lo posterior.

## Sprints incluidos

- Sprint 0.0 — Bootstrap de arquitectura, documentación y guías de IA (`CLAUDE.md`,
  `CONSTITUTION.md`).
- Sprint 0.1 — Foundation: monorepo (Turborepo + pnpm), Next.js, Prisma, Supabase.
- Sprint 0.2 — Foundation Engine: tokens de diseño (`packages/config/tokens/*.css`) y Theme
  Engine (`packages/ui/theme/`).
- Sprint 0.3 — Design System Core: 9 primitives visuales (`Surface`, `Panel`, `Window`,
  `Typography`, `Divider`, `Stack`, `Grid`, `Button`, `IconButton`) + `lib/cn.ts`.

## Funcionalidades

- Estructura de monorepo: `apps/`, `packages/`, `docs/`, `specs/`, `decisions/`, `memory/`,
  `prompts/`.
- Tokens de diseño (color, spacing, radius, elevación, borde, motion, tipografía, breakpoints,
  layout) como fuente única de verdad visual.
- Theme Engine (light/dark) funcional.
- 9 primitives del Design System, jerarquía `Surface → Panel → Window`, sin lógica de negocio,
  sin acceso a datos.
- Patrón de carpeta uniforme por componente (`component.tsx`, `types.ts`, `styles.ts`, `index.ts`,
  `tests/`, `stories.md`, `README.md`).

## Métricas

- 56/56 tests pasan (Vitest + Testing Library + `vitest-axe`, cero violaciones de accesibilidad).
- Cero errores/warnings de ESLint.
- Cero errores de TypeScript (`tsc --noEmit`, `noUncheckedIndexedAccess`).
- Cero colores/spacing/radius/shadows/duración hardcodeados fuera de tokens.

## Deuda técnica conocida

- `Tooltip` y patrón de nombre accesible compartido para controles con ícono — pendiente.
- Tokens de opacidad/alpha dedicados — pendiente (`opacity-50`/`/90` crudos de Tailwind).
- Tipografía fluida (`clamp()`) — pendiente.
- `Stack`/`Grid` responsive completo en los cinco breakpoints semánticos (hoy solo
  `tablet`/`laptop`).
- `Skeleton`, `VisuallyHidden` reutilizable — pendientes.

Ver `packages/ui/DESIGN_SYSTEM.md` → "Suggested Improvements" para detalle completo.
